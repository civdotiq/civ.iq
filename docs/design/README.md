# Design handoff archive

`civ-iq-redesign/` is the historical design handoff used for the 2026 redesign. It is kept as a record only. Its copy and code are **not current**: for example, `LandingScreen.jsx` says "MIT licensed", but the app is Apache-2.0. For current design rules, see [`../DESIGN_SYSTEM.md`](../DESIGN_SYSTEM.md).
