# CIV.IQ Web UI Kit

A pixel-faithful recreation of the CIV.IQ web app. Otl Aicher / Ulm School lineage: systematic grid, bold primary colors, uppercase display, 2px borders, no gradients, no decoration.

## Components

- `Logo.jsx` — the wordmark with the ball-and-stem "i"
- `TopNav.jsx` — fixed top navigation bar
- `AddressLookup.jsx` — the primary hero input
- `OfficialCard.jsx` — representative summary card
- `VotingRecord.jsx` — voting record list w/ alignment bars
- `MoneyPanel.jsx` — FEC money flow panel
- `SourceTag.jsx` — attribution tag (appears on every fact)
- `Chip.jsx` — party + status chips
- `Button.jsx` — primary/secondary/ghost/danger

## Screens (in `index.html`)

1. Landing — "Know your representatives"
2. Address result — list of officials tied to a ZIP
3. Official detail — Hakeem Jeffries voting record + funding

Open `index.html` to see the interactive click-thru.
