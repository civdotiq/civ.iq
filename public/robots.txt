# /api/v1/ is the public, documented, rate-limited agent API — always allowed
# (longest-match wins over Disallow: /api/). Bare /api/ stays blocked: those
# are internal UI routes backed by rate-limited upstream government APIs.
# Keeping /api/ blocked also means a crawler rendering a page never spends
# upstream quota through the page's client-side fetches.
# /api/card/ is allowed because og:image share cards live there.
# Never block /_next/: search engines need its CSS, JS and images to render pages.
