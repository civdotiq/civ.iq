# Workflow

- **Find existing patterns** before creating new abstractions — this codebase usually already has the helper.
- **Subagents for breadth**: use them for wide searches and parallel research so the main context stays clean.
- **Learn from corrections**: after a user correction, save a feedback memory so it doesn't repeat.

## When stuck

Get the exact error, look for a similar working pattern in the codebase, and prefer the simple fix. If two approaches are both reasonable and the choice matters, ask "X or Y?" rather than building a workaround.
